# تقدير التكلفة — Unlimited Photos Architecture

⚠️ هذه أرقام تقديرية بناءً على أسعار AWS المعلنة (تحقق منها في AWS Pricing Calculator قبل أي التزام تجاري، فالأسعار تتغير).

**الافتراضات:** صورة متوسطة 4MB، AWS Rekognition لكشف الوجوه (Group1 APIs ~$0.001/صورة للمليون الأولى)، تخزين S3 قياسي (~$0.023/GB/شهر)، pgvector مستضاف على نفس سيرفر Postgres (بدون تكلفة إضافية منفصلة عند هذه الأحجام).

| عدد الصور | Storage (S3) | AI Processing (Rekognition) | Vector DB | Bandwidth (تقديري) | التكلفة التقديرية الإجمالية/شهر |
|---|---|---|---|---|---|
| 1,000 | ~$0.10 | ~$1 | ضمن سيرفر DB أساسي | ~$1 | **~$5-10** |
| 10,000 | ~$1 | ~$10 | ضمن سيرفر DB أساسي | ~$5 | **~$25-40** |
| 50,000 | ~$5 | ~$50 | يحتاج DB أكبر قليلاً | ~$20 | **~$100-150** |
| 100,000 | ~$10 | ~$80-100 (يبدأ تدرج السعر) | DB متوسط + IVFFlat index | ~$40 | **~$200-300** |
| 500,000 | ~$45 | ~$300-400 | DB أقوى (RAM أعلى للـ index) | ~$150 | **~$800-1,200** |
| 1,000,000 | ~$90 | ~$600-800 | DB مخصص + tuning للـ pgvector | ~$300 | **~$1,500-2,200** |

## متى يصبح Self-hosted InsightFace أرخص من Cloud API؟

- تكلفة GPU مناسب (مثل T4/L4 على الاستضافة السحابية) تقريبًا $300-600/شهر.
- عند **~500,000+ صورة/شهر بشكل مستمر** يصبح تشغيل GPU خاص عادة أرخص من الدفع لكل صورة عبر Rekognition، لأن تكلفة GPU الثابتة تُقسّم على حجم أكبر.
- تحت هذا الحجم، Cloud API (Rekognition) أبسط تشغيليًا وأرخص فعليًا لأنك لا تدفع مقابل GPU خامل بين المناسبات.
- **التوصية العملية:** ابدأ بـ AWS Rekognition عبر `FaceRecognitionProvider` (Phase 1)، وانتقل إلى InsightFace الذاتي فقط عند تجاوز الحجم أعلاه بثبات — الـ Architecture مصممة لهذا الانتقال دون إعادة بناء.

## جدول مقارنة المزودين

| الخدمة | سبب الاختيار | السعر (تقريبي) | API | حدود الاستخدام | البديل |
|---|---|---|---|---|---|
| AWS Rekognition | نضج، دقة جيدة، Pay-per-use، لا يحتاج بنية GPU | ~$0.001/صورة أول مليون | نعم، موثق جيدًا | لا حد صارم، تدرج بالسعر | Self-hosted InsightFace عند الحجم الكبير |
| AWS S3 | معيار الصناعة لتخزين الكائنات، S3-compatible يسهّل التبديل لاحقًا لـ R2 | ~$0.023/GB/شهر | نعم | لا يوجد | Cloudflare R2 (بدون رسوم Egress، أرخص للـ bandwidth العالي) |
| Cloudflare R2 | بديل أرخص عند bandwidth عالٍ (بدون Egress fees) | تخزين مشابه، bandwidth مجاني | نعم | لا يوجد | AWS S3 |
| PostgreSQL + pgvector | يجنّب قاعدة بيانات منفصلة، يدعم RLS للعزل بين المستأجرين | تكلفة سيرفر DB فقط | SQL قياسي | يحتاج tuning عند ملايين الـ vectors | Pinecone / Qdrant عند تجاوز ~5-10 مليون embedding |
| Moyasar | مصمم للسوق السعودي، يدعم مدى | حسب نسبة المعاملة | نعم، موثق | حسب الحساب التجاري | HyperPay / Tap |

**ملاحظة أخيرة:** كل هذه الأرقام أولية لأغراض تخطيط الـ Architecture فقط، وليست عرض سعر نهائي. يجب التحقق منها عبر الحاسبة الرسمية لكل مزود قبل تسعير خطط العميل النهائية.
